# ☕ BrewSpot – Cafe Finder

BrewSpot is a modern café discovery web application that helps users find nearby cafés using an interactive map. It provides an intuitive interface to explore cafés, view details, search by location, and discover new places to work, study, or relax.

## 🌟 Features

* 🗺️ Interactive maps powered by **Leaflet.js**
* 📍 Location-based café search
* 🔎 Search cafés by name or location
* ❤️ Save favorite cafés
* 📱 Fully responsive design
* 🎨 Modern and user-friendly interface
* ⚡ Fast and lightweight performance

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* Leaflet.js
* OpenStreetMap

## 💻 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/Titli-14/Cafe_finder.git
```

2. Navigate to the project folder:

```bash
cd Cafe_finder
```

3. Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.
